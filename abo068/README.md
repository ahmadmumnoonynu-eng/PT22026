# SmartFeel AI

SmartFeel AI is a local sentiment analysis and customer experience application.
The interface uses HTML, CSS, and vanilla JavaScript; Python FastAPI serves the
frontend and API. All predictions use the existing calibrated local RoBERTa
checkpoint.

## Run locally

Use Python 3.11 from the project root:

```powershell
python -m pip install -r requirements.txt
python -m uvicorn backend.main:app --reload
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000). FastAPI serves the static
frontend as well as the API. The model loads once in the application process at
startup; it is not downloaded or retrained.

## Sections

- **Dashboard:** Counts, history-derived charts, recent saved analyses, and
  separately labeled offline test metrics.
- **AI Playground:** Analyze one text and view its predicted class and class
  probabilities.
- **ReviewAI:** Analyze a customer review with its product name.
- **SocialMind:** Analyze 2–30 comments and view each result and batch
  distribution. It opens with six fictional commenter samples, marked as demo
  data by default; analyzing them saves model-generated results with demo labels.
- **History:** Search and filter saved records, export CSV, and clear history
  after confirmation.

On the first server startup, four clearly labeled fictional customer reviews
are added to the JSON history for demonstration. Their sentiment scores are
generated by the local RoBERTa model; the reviews and customer identities are
sample content, not real customer data. A marker prevents reseeding on later
restarts, including after history is cleared.

SocialMind's fictional sample comments are only saved to history after you
analyze them. You can uncheck the demo-data option before analyzing other
comments.

## API

- `POST /api/analyze` — `{ "text": "..." }`
- `POST /api/review` — `{ "product_name": "...", "review_text": "..." }`
- `POST /api/social` — `{ "comments": ["...", "..."] }`
- `GET /api/history` — optional `search`, `sentiment`, `source`, `days`,
  `limit`, and `offset` query parameters
- `GET /api/history/export.csv` — exports matching history records
- `DELETE /api/history` — clears saved records
- `GET /api/dashboard` — history statistics, activity, recent records, and
  offline evaluation metrics; optional `days` filter for activity statistics
- `GET /docs` — interactive API documentation

The history file and model files remain in their original project-level
directories. Do not remove or replace the contents of
`models/smartfeel_roberta_calibrated_final/`.
